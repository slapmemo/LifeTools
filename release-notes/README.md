# Sürüm notları

Her yayından önce bu klasöre `vX.Y.Z.md` adıyla (etiketle aynı ad) bir not dosyası ekle ve etiketle aynı commit'e koy.
Yayın akışı (`.github/workflows/release.yml`) yayından sonra GitHub sürüm sayfasındaki metni bu dosyayla değiştirir.
Dosya yoksa sayfada yalnızca varsayılan "kendini otomatik günceller" cümlesi kalır ve akış uyarı verir.

Kullanıcıya dönük yaz: ne yeni, ne düzeldi. Kod ayrıntısı, dosya adı yazma.
